# Brand assets

Velyos brand wordmark (VELY in navy `#0B0F19`, OS in orange `#E85D1F`).

- `velyos-logo.svg` — light variant (transparent bg, dark text). Used on light backgrounds.
- `velyos-logo-dark.svg` — dark variant (navy bg, light text). Used on dark backgrounds.

The README hero uses a `<picture>` element to pick the variant by color scheme.
A square `favicon.svg` (navy "V.") lives in `web/public/` and `dj/`.

Brand palette: navy `#0B0F19`, orange `#E85D1F`, cream `#F5F3EE`.
